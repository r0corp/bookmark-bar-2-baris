Tersimpan

Bookmark Bar 2 Baris

Perubahan langsung tersimpan dan berlaku di semua tab.

Tampilan

Status server

Hanya bookmark dengan alamat yang cocok yang dicek. Tidak ada yang dikirim ke internet.

Profil Kerja / Pribadi

–

Situs dikecualikan

Contoh: klikbca.com, outlook.office.com. Subdomain ikut terkecuali.

Backup

Simpan pengaturan (termasuk warna folder) ke file untuk dipindah ke laptop lain. Bookmark-nya sendiri ikut sinkron lewat akun Chrome atau Ekspor di Kelola bookmark.

Tips

  • Sembunyikan bar asli Chrome dengan Ctrl+Shift+B supaya bookmark tidak tampil dobel.
  • Alt+Shift+B atau klik ikon ekstensi: tampilkan / sembunyikan bar. Alt+Shift+F: cari. Alt+Shift+P: ganti profil.
  • Klik tengah / Ctrl+klik: tab baru. Shift+klik: jendela baru. Klik tengah folder: buka semua.
  • Klik kanan bookmark: edit, hapus, buka Incognito. Klik kanan folder: ganti nama, warna folder.
  • Seret bookmark untuk menyusun ulang, atau ke tengah folder untuk memasukkannya. Link dari halaman juga bisa diseret ke bar.
  • Shortcut bisa diubah di chrome://extensions/shortcuts.
  • Bar tidak bisa muncul di halaman Chrome sendiri (chrome://, Web Store, tab baru).
